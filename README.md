# TaskList README
A to-do list application made with JavaFX.
Users can add any number of tasks, mark them as completed, and delete them from the list.
The UI contains a TextBox to enter the names of tasks, a ListView populated with CheckBoxes that each represent a task, and three buttons labeled "Add", "Delete", and "Mark Complete".

The project was created for a school assignment intended to teach students about the fundamentals of JavaFX and Event-Driven programming.
